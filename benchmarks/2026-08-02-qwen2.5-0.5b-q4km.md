# Qwen2.5-0.5B-Instruct Q4_K_M: CPU vs GPU Benchmark

Date: 2026-08-02

## Test platform

- Device: NVIDIA Jetson Nano Developer Kit, 4 GB
- GPU: NVIDIA Tegra X1, Maxwell, compute capability 5.3
- CUDA: 10.2.300
- `llama.cpp`: b5050, commit `23106f94e`
- Model: Qwen2.5-0.5B-Instruct Q4_K_M GGUF
- Model size: 462.96 MiB
- Parameters: 630.17 M
- CPU threads: 4
- Prompt test: `pp128`
- Generation test: `tg64`

## Results

| Mode | GPU layers | Prompt processing (`pp128`) | Token generation (`tg64`) |
|---|---:|---:|---:|
| CUDA full offload | 99 | 168.54 ± 0.98 t/s | 11.35 ± 0.01 t/s |
| CPU only | 0 | 126.45 ± 6.46 t/s | 5.83 ± 0.01 t/s |

## Derived comparison

- Prompt-processing speedup: `168.54 / 126.45 = 1.33×`
- Prompt-processing improvement: approximately `33.3%`
- Token-generation speedup: `11.35 / 5.83 = 1.95×`
- Token-generation improvement: approximately `94.7%`
- Approximate time to process 128 prompt tokens:
  - GPU: `0.76 s`
  - CPU: `1.01 s`
- Approximate time to generate 64 tokens:
  - GPU: `5.64 s`
  - CPU: `10.98 s`

## Comparison with SmolLM2-360M Q4_K_M

| Model | GPU `pp128` | GPU `tg64` | CPU `pp128` | CPU `tg64` |
|---|---:|---:|---:|---:|
| SmolLM2-360M | 154.11 t/s | 14.13 t/s | 135.21 t/s | 7.08 t/s |
| Qwen2.5-0.5B | 168.54 t/s | 11.35 t/s | 126.45 t/s | 5.83 t/s |

Relative to SmolLM2 on GPU, Qwen is approximately `9.4%` faster at prompt processing but approximately `19.7%` slower at token generation. Qwen also uses substantially more memory and drives the Nano GPU close to full utilization.

## Runtime observations

During the Qwen GPU run, `tegrastats` showed:

- GPU utilization: 98–99%
- GPU clock: 921 MHz
- GPU power: approximately 3.8–4.0 W
- Total board power: approximately 6.3–6.4 W
- RAM: approximately 2654 / 3956 MB
- Swap: approximately 110 / 1978 MB
- GPU temperature: approximately 35–35.5°C

The run completed without thermal throttling. Full GPU offload is strongly preferable to CPU-only execution for this model, nearly doubling generation throughput.

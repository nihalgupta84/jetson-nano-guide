# Benchmarks

Store reproducible CPU-only and CUDA-offload benchmark results here.

Each result should include:

- Date and time
- JetPack/L4T/CUDA versions
- `llama.cpp` commit
- Model and quantization
- Context and batch settings
- Prompt-processing tokens/s
- Generation tokens/s
- RAM, swap, temperature, and power mode
- Whether the display manager was active
